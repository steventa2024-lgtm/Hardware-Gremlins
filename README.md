### 💻 System Compatibility
* **OS:** Windows 10 / Windows 11 (64-bit)
* **Companions:** Purp (GPU Telemetry) & Volt (CPU Core Threads)

---

### 🔒 Privacy & Architecture
* **100% Local Execution:** Operates entirely offline with zero outbound network calls, background tracking, or analytics.
* **Direct Hardware Polling:** Zero-overhead metrics polled directly via native OS delta queries and `nvidia-smi`.
